# LE DERNIER RYŪ — Le Jeu 🎮

**Jeu vidéo d'action original** jouable dans le navigateur (Canvas / JavaScript, zéro dépendance) : incarnez Kaï Ryūzaki, survivez à 4 vagues d'Ombres, puis affrontez le Ryū des Ténèbres.

## 🕹️ Comment jouer
| Touche | Action |
|---|---|
| ZQSD / WASD / Flèches | Se déplacer |
| J ou Espace | Attaque au sabre |
| K ou Maj | Esquive (invincibilité brève) |
| B | **BANKAI** quand le reiatsu est à 100 % |

Sur mobile : joystick virtuel + boutons ATQ / DASH / BANKAI.

## ⚔️ Mécaniques
- **5 vagues** : les Ombres chassent en meute, de plus en plus nombreuses et rapides.
- **Jauge de reiatsu** : chaque coup porté la remplit. Les pickups (+PV / REI) lâchés par les ennemis aident à tenir.
- **Bankai Kazehikari** : 8 s de puissance — dégâts doublés, slash de vent à distance, vitesse accrue, onde de choc radiale au déclenchement.
- **Boss final** : le Ryū des ténèbres (600 PV) invoque des serviteurs et tire des rafales d'ombre.
- Score, HUD complet (PV / reiatsu / vague), écrans de victoire et de défaite, redémarrage instantané.
